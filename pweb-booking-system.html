PWeb Booking System

Sistema di gestione prenotazioni per un salone di parrucchiere, sviluppato come progetto finale del corso di Programmazione Web all'Università di Pisa. I clienti si registrano e prenotano appuntamenti online; lo staff gestisce prenotazioni, clienti e no-show da una dashboard dedicata.

Voto 30/30 Repository privata
01

Funzionalità

Lato cliente

  • Registrazione e login con validazione server-side
  • Prenotazione appuntamenti con scelta del servizio
  • Area personale per gestire le prenotazioni e il profilo

Lato amministratore

  • Dashboard con tutti gli appuntamenti in arrivo
  • Gestione clienti
  • Blacklist per i no-show ripetuti ("ghost booking")
02

Sicurezza

  • Prepared statements (mysqli) contro SQL injection
  • Verifica token CSRF sui form di autenticazione (login, registrazione, cambio password)
  • Timeout di sessione dopo 30 minuti di inattività
  • Controllo "ghost session" — invalida le sessioni legate a utenti eliminati
  • Validazione server-side degli input (es. formato email)
03
